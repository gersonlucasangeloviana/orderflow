# Migração Xamarin.Forms para .NET MAUI

Xamarin.Forms é legado e não deve receber recursos novos. Manter o cliente REST isolado; portar modelos e serviços para um projeto compartilhado, migrar páginas para `ContentPage` MAUI, substituir renderers por handlers e trocar bibliotecas incompatíveis. Validar Android/iOS em CI antes da troca gradual de distribuição. O módulo não é implantado no Dokploy.
